# 党建会议记录生成器

本工具在本机运行，浏览器页面用于选择会议类型、录入议题、参会人员和书记姓名；DeepSeek API 密钥只在本地服务端读取，不会暴露给网页前端。

## 项目目录

| 目录或文件 | 内容 |
| --- | --- |
| `server.js`、`public/` | 当前桌面网页版源码 |
| `fnos-app/` | 飞牛 fnOS 源码、测试、安装包与安装说明 |
| `halo-plugin-dangjian/` | Halo 插件源码、测试与 Gradle 构建文件 |
| `Halo插件交付/` | Halo 插件 JAR、源码压缩包及安装说明 |
| `dist/` | Windows 可执行程序与无密钥分发包 |
| `party-record-generator/` | 保留的早期桌面版副本，当前版本请使用项目根目录 |

本地密钥、依赖缓存、构建缓存及浏览器测试记录不纳入 Git。克隆项目后按各版本说明配置自己的密钥；预览图片中的生成结果使用模拟数据。

## 使用方式

首次从 GitHub 下载后，将 `.env.example` 复制为 `.env`，填写自己的 `DEEPSEEK_API_KEY`，再启动程序。仓库不包含任何预设密钥。

1. 双击 `双击启动网页.command` 或 `启动.command`。
2. 程序会自动打开 `http://127.0.0.1:8787`。
3. 选择“主题党日”“党员大会”或“支委会”，填写学习议题和人员后点击“生成记录”。
4. 选择“支委会”后，可编辑“支部事项”，每行一项；默认包含党员大会议程及组织安排、党员发展及培养考察安排，留空时使用默认事项。生成结果会在学习议题之后逐项加入委员讨论、书记归纳和后续安排。支委会仅使用书记、副书记和委员作为参会及发言人员。

会议类型会显示在生成记录标题和下载文件名中。切换类型会保留已填写的学习议题、成员和支部事项。具体讨论内容和决定请按实际会议情况补充、核对。

修改程序后，如服务已在运行，需关闭原启动窗口并重新启动。

如端口被占用，可修改 `.env` 中的 `PORT`。

默认使用 `deepseek-v4-flash`。如需更强生成质量，可把 `.env` 中的 `DEEPSEEK_MODEL` 改为 `deepseek-v4-pro`。

## 飞牛 fnOS 应用

飞牛版本位于 `fnos-app/`，与本地桌面版、Windows 版和 Halo 插件分开维护。安装包为 `fnos-app/dist/DangjianRecorder.fpk`，安装步骤及数据备份说明见 [飞牛应用说明](fnos-app/README.md)。

安装后从飞牛桌面打开应用，在网页“应用设置”中填写 DeepSeek API 密钥。密钥保存在飞牛的应用数据目录，不会随安装包分发；原项目的 `.env` 不会打进飞牛包。

```sh
npm run test:fnos
npm run build:fnos
```

## Windows exe 打包

可直接下载 `dist/党建会议记录生成器-Windows-无密钥.zip`，解压后在 `.env` 中填写自己的 API 密钥，再运行。该分发包保留可执行程序、启动脚本和说明，配置中的密钥为空。

在项目目录执行：

```bash
npm install
npm run build:win
```

打包完成后，Windows 64 位版本在 `dist/党建会议记录生成器.exe`，建议在 Windows 10/11 上使用。运行时和网页已内置，不需要安装 Node.js。把 `.env` 放在 `.exe` 同一目录，双击 `.exe` 后会自动打开浏览器页面；生成内容需要联网。

如浏览器未自动打开，可手动访问 `http://127.0.0.1:8787`。使用期间保留程序窗口，关闭窗口即停止本地服务。
