# 党建会议记录生成器 · Halo 插件

将原本需要在本机运行的会议记录工具集成到 Halo。默认访问地址是 `https://你的域名/dangjian`，可在 Halo 插件设置中修改路径。保留主题党日、党员大会、支委会、学习议题、支部事项、人员编辑、公开材料检索、结果编辑、复制和 TXT 下载。

## 环境

- Halo **2.26.0 或以上的兼容版本**；本项目使用官方脚手架和 Halo 2.26.0 平台依赖。
- Halo 服务端可以访问 DeepSeek API；开启参考检索时还需访问搜狗、360、Bing 和允许的公开材料网站。
- 使用时无需在服务器额外运行 Node.js 服务。

## 安装与配置

1. 进入你的 Halo 管理后台：**插件 → 安装插件 → 上传插件**。
2. 上传 `build/libs/plugin-dangjian-1.0.0.jar`（或交付目录中的同名 JAR）。
3. 打开“党建会议记录生成器”的设置。
4. “访问路径”默认填写 `/dangjian`。也可填写 `/meeting` 或 `/tools/dangjian`。允许英文字母、数字、连字符和下划线，路径最长 128 字符，不允许覆盖 `/console`、`/api` 等 Halo 系统路径。
5. 在“DeepSeek API 密钥”中创建或选择 Halo Secret，并填写其 `token`。密钥始终只保存在 Halo 服务端，不会写入插件 JAR、公开页面或普通配置。
6. “DeepSeek 模型”默认保留原程序的 `deepseek-v4-flash`。根据 DeepSeek 账号实际可用模型修改该名称。
7. 保存设置，启用插件，访问 `https://你的域名/dangjian`。

页面可公开访问，生成默认需要登录 Halo。需要让访客使用时，在设置中显式开启“允许未登录访客生成”。可调整每个用户或访客的每分钟生成次数（1–30，默认 3）；同时最多处理 4 个生成请求。

### 修改访问地址

在插件设置中将“访问路径”从 `/dangjian` 改为 `/meeting` 后保存，即可访问 `https://你的域名/meeting`。新路径下的资源和生成接口自动跟随，无需重新打包或配置一个独立端口。原路径停止提供本插件页面，由 Halo 继续处理。

请选择没有被文章、独立页面或其他插件使用的地址。若网站反向代理已经把所有请求转发给 Halo，无需添加单独的 `/dangjian` 转发规则。

### 使用与数据

- 支委会仅使用书记、副书记和委员作为参会人员，保留支部事项的默认值与自定义编辑。
- 首个议题包含领学、两人分享和书记总结；后续学习议题按原工具格式摘取或整理材料。支部事项接在学习议题之后，未提供的人员、日期、票数及审批结论不应编造。
- 结果可直接在页面修改，复制或下载为按会议类型命名的 `.txt` 文件。
- 插件不额外持久化会议记录。刷新页面前请复制或下载需要保留的内容。
- 生成会将议题、参会姓名和检索摘录发送到 DeepSeek。内容是生成草稿，请按实际会议核对后使用。
- 检索仅访问允许的公开网站；无可用材料时页面会显示回退来源，仍可按题目生成。

## 构建与测试

构建需要 Java 21 和网络连接，Gradle wrapper 已包含在项目中：

```bash
./gradlew clean build
```

JAR 位于 `build/libs/plugin-dangjian-1.0.0.jar`。后端测试覆盖会议规则、输入限制、路径设置、Secret 读取、鉴权、CSRF、频率/并发限制、参考检索防护和上游 API 错误。

前台浏览器测试使用 Node.js、Playwright 和 Chrome：

```bash
npm install --no-save --package-lock=false playwright
node --test tests/website.test.cjs
```

可在安装了 Docker 的开发机使用官方 DevTools 运行 Halo：

```bash
./gradlew haloServer
```

## 常见问题

- **页面提示配置未完成**：检查 DeepSeek Secret 是否存在、`token` 是否填写，以及插件设置是否保存。
- **生成请求提示安全校验失效**：重新读取配置或刷新页面，重新取得 Halo 的 CSRF 令牌；登录状态变化后也应刷新。
- **DeepSeek 密钥无效、额度不足或模型不可用**：检查开放平台账号与插件设置。
- **新路径返回其他内容**：检查是否与 Halo 页面、文章或其他插件冲突，以及插件是否已启用。
- **检索结果为空**：确认 Halo 服务器出站网络是否可用；检索失败不会中断纯题目生成。
